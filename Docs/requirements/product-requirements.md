## 1. 產品目標

讓「知道自己大致想讀什麼、但不知道具體書名」的使用者，從真實書籍資料中找到想讀的書。

**User Story**

> 作為一名知道自己大致想閱讀什麼、但不知道具體書名的使用者，我希望能以自然語言描述閱讀需求，讓系統從真實書籍資料中找出並推薦適合的書籍，說明推薦理由，並讓我將感興趣的書加入個人書單、管理閱讀狀態與評分。

不相關的推薦不符合此 User Story；寧可推薦較少或不推薦，也不推薦不相關的書。

## 3. 功能規則

規則編號供 issue、測試與 PR 引用。修改規則時保留編號，刪除時標記 `[已移除]`，不重複使用編號。

### 3.1 博客來暢銷榜爬取（CRAWL）

- **CRAWL-01** 每日一次，取得博客來中文書 7 日暢銷總榜 TOP 100 的排名與商品網址。
- **CRAWL-02** 以博客來商品網址判斷 Book 是否已存在。
- **CRAWL-03** 只有不存在的 Book 才抓取商品詳細資料；已存在的 Book 不因每日爬取而更新 metadata。
- **CRAWL-04** 新書詳細資料抓取失敗時重試，仍失敗則該書在本次榜單中被跳過，保留其他書的原始排名。
- **CRAWL-05** 單次被跳過的書不超過 10 本時，視為部分成功並替換榜單；超過 10 本或排行榜本身無法完整解析時，整次失敗，保留上一份榜單。
- **CRAWL-06** 只保存最新一份 Bestseller。

### 3.2 暢銷榜瀏覽（BEST）

- **BEST-01** 任何人皆可查看目前 Bestseller 的排名、封面、書名、作者，並進入 Book 詳細頁。
- **BEST-02** 顯示榜單更新時間。
- **BEST-03** 排名依博客來原始排名顯示；被跳過的排名不顯示，不重新編號。
- **BEST-04** 尚無任何榜單時顯示「榜單尚未建立」空狀態。

### 3.3 一般搜尋（SEARCH）

- **SEARCH-01** 單一搜尋框；只查詢本地資料庫，任何情況都不呼叫 Google Books。
- **SEARCH-02** 輸入為 ISBN 格式時以 ISBN 精確比對；否則以書名、作者做不分大小寫的部分比對。
- **SEARCH-03** 查無結果回傳空結果；空白輸入回傳空結果。
- **SEARCH-04** 結果分頁，每頁 20 筆。

### 3.4 Book 詳細頁（BOOK）

- **BOOK-01** 顯示 Book 的書名、副標題、作者與其他貢獻者、出版社、出版日期、簡介、ISBN、分類、頁數、封面、目錄（若有）。
- **BOOK-02** 每個 Book Source 各提供一個外部連結，供使用者購買或閱讀。
- **BOOK-03** 來源只提供年份或年月的出版日期，依實際精度顯示，不補成完整日期。
- **BOOK-04** 已登入且該書在 Library 中時，顯示並可直接修改 Reading Status 與評分。

### 3.5 帳號（AUTH）

- **AUTH-01** 以 email、密碼、顯示名稱註冊；email 不分大小寫唯一；密碼至少 8 碼。
- **AUTH-02** 以 email、密碼登入；失敗時不透露 email 是否已註冊。
- **AUTH-03** 登入狀態維持 1 天，到期需重新登入。
- **AUTH-04** 可登出。
- **AUTH-05** 可取得目前使用者資訊。

### 3.6 Library（LIB）

- **LIB-01** 已登入使用者可將 Book 加入 Library，預設 Reading Status 為想讀；重複加入不改變既有狀態。
- **LIB-02** 未登入使用者加入時先導向登入；登入後自動完成加入並回到原 Book 詳細頁。
- **LIB-03** 可查看 Library，並依 Reading Status 篩選。
- **LIB-04** 可修改 Reading Status：想讀、閱讀中、已讀。
- **LIB-05** 可給予 1～5 星評分，或清除評分；任何 Reading Status 皆可評分。
- **LIB-06** 可移除 Library Entry；移除後評分一併消失。

### 3.7 AI 推薦（REC）

- **REC-01** 需登入才能使用 AI 推薦。
- **REC-02** 使用者以自然語言輸入閱讀需求。
- **REC-03** 系統優先從本地資料庫找出 Candidate Set；只有 Candidate Set 少於 5 本時才查詢 Google Books，結果正規化寫入本地資料庫後才可成為候選。
- **REC-04** 使用者需求中明確提到的條件（語言、出版時間、頁數、作者、出版社）作為硬性過濾；使用者沒提到或語意不確定的條件不得加入過濾。
- **REC-05** 只有與需求足夠相關的書可以成為候選；不相關的書即使通過過濾也不推薦。
- **REC-06** AI 只能推薦 Candidate Set 中的書，每次最多 10 本；候選不足或不相關時可少於 10 本，也可以是 0 本並明確告知。
- **REC-07** 每本推薦結果附推薦理由與相關度；難度在可取得時顯示。
- **REC-08** 博客來排名不影響推薦排序；排序依據為使用者需求與 Book metadata。
- **REC-09** 成功的推薦（含 0 本結果）保存為 Recommendation Search；失敗不保存並告知使用者。
- **REC-10** 使用者可查看自己的 AI 搜尋紀錄列表與每次的推薦結果；結果為當時的快照，不重新推薦。
- **REC-11** 每位使用者每日（Asia/Taipei）最多 20 次 AI 推薦；超過時告知今日次數已用完。

## 4. 驗收條件

### CRAWL

- **Given** 排行榜可解析 100 筆，其中 3 本新書詳細頁重試後仍失敗，**When** crawler 執行完成，**Then** Bestseller 被替換為 97 筆、保留原始排名，run 記錄為部分成功。
- **Given** 有 11 本新書詳細頁失敗，**When** crawler 執行，**Then** run 失敗，上一份 Bestseller 不變。
- **Given** 某商品網址已存在於資料庫，**When** crawler 執行，**Then** 不抓取該書詳細頁，Book metadata 不變。

### BEST

- **Given** 資料庫中沒有任何 Bestseller，**When** 使用者開啟暢銷榜，**Then** 顯示「榜單尚未建立」，不顯示錯誤頁。
- **Given** 第 37 名在本次爬取被跳過，**When** 使用者開啟暢銷榜，**Then** 顯示第 36 名後接第 38 名。

### SEARCH

- **Given** 本地資料庫查無符合書籍，**When** 使用者搜尋，**Then** 顯示空結果，且系統沒有呼叫 Google Books。
- **Given** 使用者輸入 `978-986-xxx` 形式的 ISBN，**When** 搜尋，**Then** 只回傳 ISBN 完全相符的 Book。

### LIB

- **Given** 使用者未登入，**When** 在 Book 詳細頁按「加入書單」並完成登入，**Then** 該書已在 Library 中且回到原 Book 詳細頁。
- **Given** 書已在 Library 中且狀態為閱讀中，**When** 再次加入，**Then** 狀態仍為閱讀中。

### REC

- **Given** 使用者未登入，**When** 送出 AI 推薦，**Then** 導向登入頁，不呼叫任何外部 AI 服務。
- **Given** 需求為「想看輕鬆的推理小說」（未提及語言、年份、頁數、作者、出版社），**When** 推薦，**Then** 不套用任何硬性過濾。
- **Given** 本地相關候選少於 5 本，**When** 推薦，**Then** 查詢 Google Books，新書寫入本地資料庫後才參與推薦。
- **Given** 本地相關候選 ≥ 5 本，**When** 推薦，**Then** 不呼叫 Google Books。
- **Given** AI 回傳了不在 Candidate Set 中的書，**When** 系統處理結果，**Then** 該書不出現在推薦結果中。
- **Given** 使用者今日已成功推薦 20 次，**When** 再次送出，**Then** 告知今日次數已用完，不呼叫外部服務。
- **Given** OpenAI 呼叫失敗，**When** 推薦，**Then** 顯示錯誤訊息，AI 搜尋紀錄中沒有這次搜尋。
